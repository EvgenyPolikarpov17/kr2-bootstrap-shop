# ShopProject — контрольная работа № 2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

ShopProject — учебный интернет-магазин с товарами для учёбы и рабочего места. Эта версия создана как отдельная реализация первой контрольной работы с использованием Bootstrap, а не как простое перенесение прежней CSS-вёрстки.

## Технологии

- HTML5 и семантическая разметка;
- Bootstrap 5.3.6, CSS и JavaScript Bundle подключены локально;
- собственные правила в `css/custom.css`;
- JavaScript для фильтрации и сортировки каталога, выбора товара и проверки формы;
- Git / GitHub.

## Запуск

Откройте папку проекта в Visual Studio Code и запустите `index.html` через Live Server. Можно открыть HTML-файлы напрямую в браузере, но Live Server удобнее при разработке. Интернет для работы Bootstrap не нужен, так как библиотека хранится внутри проекта.

## Подключение Bootstrap

Bootstrap подключён **локально**, без CDN:

- `vendor/bootstrap/css/bootstrap.min.css` — стили Bootstrap 5.3.6;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript Bundle с Popper;
- `css/custom.css` подключается после Bootstrap, поэтому собственные настройки могут переопределять стандартные стили.

Файлы Bootstrap распространяются по лицензии MIT; исходные заголовки лицензии сохранены в файлах библиотеки.

## Реализованные страницы

- `index.html` — главная страница, hero-блок, преимущества, популярные товары и FAQ;
- `catalog.html` — каталог из шести товаров, фильтрация по категории, цене, наличию и предложению, поиск, сортировка и модальная форма;
- `product.html` — карточка выбранного товара, характеристики в адаптивной таблице и FAQ-аккордеон;
- `order.html` — форма заявки с обязательными полями, подсказками и браузерной валидацией;
- `contacts.html` — контактные способы связи и FAQ.

## Компоненты и классы Bootstrap

- сетка: `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`;
- адаптивная навигация: `navbar`, `navbar-expand-lg`, `navbar-toggler`, `collapse`;
- карточки и действия: `card`-подход в сочетании с `btn`, `badge`;
- сообщения: `alert`, включая состояния `info`, `success` и `warning`;
- модальное окно: `modal`, `modal-dialog`, `modal-content`;
- формы: `form-control`, `form-select`, `input-group`, `input-group-text`, `form-check`, `invalid-feedback`;
- дополнительные компоненты: `accordion`, `breadcrumb`, `table-responsive`;
- адаптивные утилиты: `d-flex`, `flex-wrap`, `gap-*`, `text-*`, `mb-*`, `py-*`.

## Самостоятельные доработки

1. Локальное подключение Bootstrap без CDN, чтобы библиотека работала при отсутствии сети.
2. Дополнительная страница `contacts.html` сохранена из структуры первой контрольной работы.
3. Каталог: поиск по названию, фильтр по категориям, диапазону цен, наличию и товарам со скидкой/новинкам; сортировка по цене и названию; счётчик результатов и состояние «ничего не найдено».
4. Страница товара выбирает содержимое по параметру URL, например `product.html?id=backpack`.
5. Ссылка на товар передаёт его в форму, например `order.html?product=planner`.
6. Быстрая заявка открывается через Bootstrap Modal; выбранный товар заполняется автоматически.
7. Формы проверяют обязательные поля и показывают понятное состояние после проверки. Данные не отправляются, так как backend в задании не реализован.
8. Добавлены адаптивная таблица, аккордеон FAQ, хлебные крошки, пустое состояние фильтрации, собственные CSS-стили и локальные фотографии товаров в форматах WebP и JPEG.
9. Обновлён визуальный стиль: тёплый фон цвета бумаги, кирпично-красный акцент в тон ежедневнику, аккуратные линии вместо тяжёлых теней, подчёркивание активного пункта меню и отдельная зона товара на главной. Используются системные шрифты, внешние шрифтовые сервисы и градиентные фоны не подключаются.
10. Фотографии товаров размещены на спокойном фоне; пропорции изображений сохраняются, чтобы предметы не обрезались. Используются фотографии: красный ежедневник, чёрный органайзер, песочный рюкзак, белая лампа, розовый пенал и чёрная бутылка. Для карточек используется `object-fit: contain`, чтобы товары не обрезались.

## Обновлённое оформление

Визуальный стиль собран вокруг темы канцелярии: тёплый почти белый фон, тёмный текст и красный акцент, повторяющий цвет ежедневника. На главной странице у выбранного товара есть подпись с названием и ценой; карточки не используют большие тени и чрезмерные скругления. На странице товара убрано информационное сообщение, которое повторяло очевидный текст и занимало место над карточкой. Подвал расположен внизу коротких страниц за счёт Flexbox и не перекрывает содержимое длинных страниц.

## Проверка проекта

1. На каждой странице откройте мобильное меню при узкой ширине окна.
2. В каталоге попробуйте поиск, фильтр цены, категории, наличия и скидки; проверьте сортировку.
3. Откройте `product.html?id=backpack` и проверьте цену и характеристики.
4. Нажмите «Заказать» на карточке — модальное окно должно выбрать этот товар.
5. Перейдите на `order.html?product=organizer`, убедитесь, что товар выбран автоматически.
6. Попробуйте отправить пустую форму и заполненную форму. Успешное состояние является демонстрацией проверки, а не настоящей отправкой на сервер.
7. Проверьте ширины около 375 px, 768 px и 1280 px, чтобы убедиться, что сетка не создаёт горизонтальную прокрутку.

## Вопросы для самопроверки

**Зачем нужен `container`?** Он ограничивает ширину содержимого и выравнивает блок по центру.

**Чем отличаются `row` и `col-*`?** `row` организует строку сетки, а классы `col-*` задают ширину колонок на разных размерах экрана.

**Зачем `custom.css` подключён после Bootstrap?** Чтобы собственные стили могли переопределять значения фреймворка.

**Почему для модального окна нужен Bootstrap Bundle?** Он содержит JavaScript Bootstrap и зависимости, необходимые интерактивным компонентам.

**Отправляются ли данные формы?** Нет, форма только проверяет заполнение в браузере. Для передачи данных нужен backend.
